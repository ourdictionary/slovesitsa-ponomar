- **Как внесены правки.** Файлы «Пономаря» не менялись. Каждая правка — строка в таблице: что было, что стало, основание, печатная книга. Даты — в таблице «Что изменено». Правки вносятся при сборке.

## Номера стихов
- `numbering/psalter_printed_verses.tsv` — стих «Пономаря» → номер стиха в Следованной Псалтири 1978. Сайт показывает печатный номер (11.11.2026; 20 сомнительных номеров сверены по тексту 15.11.2026).
- `numbering/ot_slavonic_synodal.tsv` — какие стихи славянского текста и синодального перевода Ветхого Завета ставить рядом (13.11 и 15.11.2026). Где стихи не сходятся, синодальная глава показывается целиком.

## Что сайт делает при показе
- В синодальном переводе два дефиса « -- » показываются тире « — », разорванный дефис («что-- нибудь») — обычным.
- В часах вместо Иисусовой молитвы стоит указание читать её: в «Пономаре» она набрана без титл, и сверить её пока не с чем. В Царских часах опущены пасхальные замены. Части, зависящие от дня, отмечены пометкой.
- В Псалтири синодальный перевод ставится рядом со славянским стих к стиху; пары подбираются через перевод П. А. Юнгерова. Где пары не сошлись, псалом показывается целиком.
- Церковнославянский текст можно переключить на гражданские буквы — это преобразование при показе.

## Формат книги
`{"book", "kind": "elis"|"synod", "source", "counts", "chapters"}`. Глава: `{"n", "heading", "verses"}`; `heading` — надписание псалма. Стих: `{"n", "text", "lead", "tokens", "zachalo"}`, где `tokens` — слова со знаками после них (`{"w", "s"}`), а `text` = `lead` + все `w` + `s`.
Необязательные поля: `var` — разночтение на полях; `it` — курсив синодального перевода (слова, добавленные переводчиком); `appendix` — строки после последнего стиха книги; `moved` — что перенесено при сборке Ветхого Завета; `syn` и `print` — синодальное место и печатный номер у стихов Исхода 36–39; `corrections` и `zachalo_fixes` — правки, внесённые в книгу.

## Источники сверки
- Печатные книги — собрание [cu-books](https://github.com/slavonic/cu-books), коммит `e3900b3c` (MIT License, Copyright (c) 2018 Slavonic Computing Initiative). Отсюда в хранилище только ссылки на листы и номера стихов.
- Скан Елизаветинской Библии 1762 года — archive.org, `1762_20211101`.
- Границы стихов Исхода 36–39 — по набору «Азбуки веры» (azbyka.ru). В таблице только номера слов, текста «Азбуки» нет.
- Шаблоны часов в «Пономаре» взяты с orthlib.ru (так указано в самом «Пономаре», `Text/*Source.xml`).

## Как собрать
```
git clone --bare https://github.com/typiconman/Ponomar.git ../Ponomar.git
bash build.sh ../Ponomar.git
```
Нужен Python 3.9 или новее, сторонние пакеты не нужны. `build.sh` собирает все файлы заново и сверяет их с `SHA256SUMS`.

## For the Ponomar authors
This repository holds the Ponomar texts used on slovesitsa.org, built from commit `0af645f4`, with corrections found while checking them against printed books. Ponomar's own files are not changed. Every correction is a row in a TSV table: what was, what became, the basis and the printed witness. The corrections are applied at build time. You are welcome to take any of them upstream.
